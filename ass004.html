Section 1: URL Breakdowns

  1. https://shop.example.com/products/shoes/25?currency=NGN&size=42
    • Protocol: https
    • Subdomain: shop
    • Domain: example.com
    • Path: /products/shoes/25
    • Query String: ?currency=NGN&size=42
    • Query Parameters:
    • currency = NGN
    • size = 42

  2. https://www.youtube.com/watch?v=abc123
    • Protocol: https
    • Subdomain: www
    • Domain: youtube.com
    • Path: /watchQuery
    • String: ?v=abc123
    • Query Parameters:
    • v = abc123

  3. http://localhost:3000/api/users/15
    • Protocol: http
    • Subdomain: none
    • Domain: localhost
    • Path: /api/users/15
    • String: none
    • Query Parameters:none

Section 2: Answer in your own words:

  • What are DNS, an IP address, a domain name, localhost, and a port?
    • DNS (Domain Name System): The internet's directory that translates human-friendly web names into numeric codes. that is the simple and straightforward words we type into browswer is being converted to number(bits)which is what is understood by computers.
    • IP Address: A unique numerical address (like 192.168.1.1) assigned to every single device on a network where they can be located.
    • Domain Name: A textual, human-friendly alias (like google.com) that points directly to a server's IP address.
    • localhost: A standard network loopback location that refers directly back to the computer you are currently working on.
    • Port: A virtual slot or channel number on a computer used to route data traffic to a specific software program or application.

    What does localhost:3000 mean?

    It tells the browser to look inside my local machine (localhost) and communicate with whatever application running on port channel 3000 (commonly a Node.js or React developer server).

    Why are domains easier for humans than IP addresses?

    it is easier for Humans because we remember descriptive words and patterns much better than abstract, long strings of random numbers. Remembering youtube.com is effortless, whereas memorizing its shifting, numerical IP addresses is highly impractical.
