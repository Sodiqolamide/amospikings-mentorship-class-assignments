      7. Why every operation should not happen inside the browser:
    • Security Vulnerabilities: Frontend code is completely public which means anybody on the web can see at anytime without any restriction. If credentials, database passwords, or private business keys are calculated in the browser, users can easily extract them.
    • Performance Bottlenecks: Older computers or low-end mobile devices will lag or completely freeze if forced to execute heavy algorithms or raw data heavy processing locally
    • Data Integrity Risks: Browsers cannot communicate between distinct client devices natively. Without a centralized server checking resources, operations like booking a seat or transferring money would suffer from overlapping conflicts and fraud
